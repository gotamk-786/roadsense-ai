# Dataset Sources

Free-first dataset strategy for RoadSense AI resume MVP.

## RDD2022

URL: https://arxiv.org/abs/2209.08538

Use for potholes, road damage, cracked/broken road examples.

Rules:
- Use for training/testing only after checking terms.
- Do not commit full dataset to GitHub.
- Keep download instructions and license notes in docs.

## Roboflow Universe

URL: https://universe.roboflow.com

Search:
- pothole detection
- road damage detection
- speed breaker detection
- road obstacle detection

Rules:
- Use only datasets with clear public/open license.
- Record dataset name, URL, license, classes, and download date.

## Kaggle

URL: https://www.kaggle.com/datasets

Search:
- pothole detection dataset
- road damage detection dataset
- road surface defect dataset

Rules:
- Each Kaggle dataset has its own license.
- Use only academic/portfolio-friendly datasets.
- Do not redistribute files unless license allows.

## Self-Collected Local Data

Use phone-recorded local road images/videos for Pakistan-style roads.

Rules:
- Record safely; do not operate phone while driving.
- Avoid faces and license plates.
- Blur sensitive content before public demos.
