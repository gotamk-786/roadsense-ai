# 10 - Quality Checklist

## Code Quality

- Clear folder structure
- Small services/components
- No hardcoded paid API keys
- Local/free defaults
- TypeScript checks pass for mobile/backend
- Python scripts compile

## AI Quality

- Dataset source documented
- Classes documented
- Train/val/test split exists
- Metrics reported
- Demo video tested

## Mobile Quality

- Camera opens
- Alerts do not spam
- History saves correctly
- GPS permission handled
- UI readable on phone

## Backend Quality

- Health endpoint works
- Create hazard works
- Nearby hazards work
- Status update works

## Portfolio Quality

- README is clear
- Setup commands work
- Screenshots/demo added
- Limitations are honest
- Future work is realistic
