# 01 - Project Overview

## Project Name

RoadSense AI - Real-Time Road Hazard Detection Mobile App

## Problem

Drivers and bike riders often face unexpected potholes, broken roads, speed breakers, animals, pedestrians, and obstacles. Late reaction can cause accidents, vehicle damage, or unsafe braking.

## Solution

RoadSense AI uses a mobile camera feed and computer vision to detect road hazards in real time. The app gives voice and vibration alerts, saves GPS-based detection history, and prepares a backend flow for community hazard reporting.

## MVP Features

- Live camera screen
- Hazard bounding boxes
- Voice alerts
- Vibration alerts
- GPS location logging
- Detection history
- YOLO training pipeline
- Local backend API
- Dataset documentation

## Free-First Strategy

The MVP uses free/local tools so it is suitable for a resume, LinkedIn, GitHub portfolio, and university demo.

Current free stack:

- React Native + Expo
- Python + YOLO + OpenCV
- Node.js + Express local backend
- AsyncStorage for local app history
- Public/free datasets and self-collected data

Commercial features are future work.
